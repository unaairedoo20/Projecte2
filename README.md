Funcions - Exercici 5

4. Quina diferència hi ha entre print() i return?

print() serveix per mostrar informació per pantalla, mentre que return serveix per retornar un valor d'una funció per poder utilitzar-lo després.

5. Per què és millor dividir un programa en funcions?

Perquè el codi queda més ordenat, és més fàcil d'entendre i podem trobar i solucionar errors més ràpidament.

6. Què és un paràmetre?

És una variable que posem dins dels parèntesis quan definim una funció i que serveix per rebre dades.

7. Què és una variable local?

És una variable que es crea dins d'una funció i que normalment només es pot utilitzar dins d'aquella funció.

8. Quins avantatges té reutilitzar una funció?

Ens permet estalviar temps, evitar repetir codi i fer que el programa sigui més fàcil de modificar.
